# Les modèles du client public — 19/10/2026

Rédigés sur les sources relevées le 19/10/2026 (audit stratégique, lot 1 bis ; registre
`parametres.ts`, entrées du code de la commande publique). Aucun n'a été validé par un avocat :
`valideParAvocat` reste `false`. Ils suivent la règle des modèles du 25/09/2026
(`../2026-09-25-modeles/README.md`) : le texte est fixe, seules les variables se remplissent, et
un gabarit qui manque d'une donnée refuse en la nommant.

- [Demande de paiement des intérêts moratoires](reclamation-interets-moratoires.md) — L'acheteur
  public (son ordonnateur), pour des factures réglées après le délai de paiement. Ton de rappel
  réglementaire, au seul nom du créancier, sans menace. Le gérant l'envoie lui-même (Chorus Pro,
  courrier ou e-mail).
- [Signalement pour mandatement d'office](signalement-mandatement-office.md) — Le préfet du
  département (collectivité territoriale) ou le directeur général de l'agence régionale de santé
  (établissement public de santé), quand les intérêts n'ont pas été mandatés dans les trente jours
  du paiement du principal. Démarche administrative, que seul le gérant décide. La chambre
  régionale des comptes, juridiction, n'est jamais proposée.
